Notepad Web

Version {{ version }}

A modern, feature-rich web-based note-taking application built with Flask and SQLAlchemy.

Features

  • Rich text editing with Quill 2.0.3
  • Real-time search across all notes
  • Grid and list view layouts
  • PDF export (individual and bulk)
  • AI writing assistant via Ollama
  • Responsive design for desktop, tablet, and mobile
  • SQLite database for fast, lightweight storage

Technical Stack

  • Backend: Flask 3.1+
  • Database: SQLAlchemy 3.1+ with SQLite
  • Rich Text Editor: Quill 2.0.3
  • PDF Generation: ReportLab 4.4+
  • Frontend: HTML5, CSS3, Vanilla JavaScript
