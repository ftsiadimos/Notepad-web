Notepad Web

Version {{ version }}

A modern, feature-rich web-based note-taking application built with Flask and SQLAlchemy. Designed for simplicity, speed, and elegance.

✨ Features

📝

Rich Text Editing

Powerful editor powered by Quill 2.0.3 with formatting tools

🔍

Instant Search

Real-time search across all your notes

📊

Dual View

Switch between grid and list layouts

📄

PDF Export

Export individual notes or bulk export all notes

🤖

AI Assistant

Built-in AI writing help via Ollama

📘

Word Export

Export notes to Microsoft Word (.docx) format

📱

Responsive

Works beautifully on desktop, tablet, and mobile

🛠️ Technical Stack

Backend Flask 3.1+
Database SQLAlchemy 3.1+ (SQLite)
Editor Quill 2.0.3
PDF ReportLab 4.4+
Frontend HTML5, CSS3, Vanilla JS
